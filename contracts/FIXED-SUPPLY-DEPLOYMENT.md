# FLASHBOYS fixed-supply token deployment

## Current integration

The Launchpad creator form now has wallet-signed **test-network-only** deployment paths:

- Solana: `src/solanaFixedSupplyLaunch.js` creates a standard SPL Token mint on Devnet, mints exactly 1,000,000,000 tokens to the connected wallet, and revokes both mint and freeze authority in the same wallet-approved transaction. It reads the mint account back and verifies the exact supply and null authorities.
- Robinhood Chain: `src/robinhoodFixedSupplyLaunch.js` deploys `contracts/RobinhoodFixedSupplyToken.sol` to Robinhood Chain Testnet (chain ID 46630). The ERC-20 contract has a fixed total supply and no mint or owner function. The app verifies total supply, deployer balance, and decimals after deployment.

The Robinhood contract artifact is generated by `scripts/compile-robinhood-token.mjs`. `npm run build` invokes this through the `prebuild` lifecycle script; `solc` is a development dependency.

## Test networks

- Solana Devnet RPC: `https://api.devnet.solana.com` (or `VITE_SOLANA_DEVNET_RPC`). The connected wallet needs Devnet SOL for rent and transaction fees.
- Robinhood Chain Testnet: chain ID `46630` (`0xb626`), RPC `https://rpc.testnet.chain.robinhood.com`, explorer `https://explorer.testnet.chain.robinhood.com`. The connected wallet needs test ETH.

## Important limitations

- These flows do not create a bonding curve, liquidity pool, automated graduation, fee routing, or buy/sell interface.
- Pinata metadata upload is not yet attached to the Solana mint as Metaplex on-chain metadata.
- Solana test creation uses the standard SPL Token program and a 9-decimal mint.
- Mainnet deployment is intentionally disabled in this integration. Do not change network constants to mainnet without end-to-end tests and an independent security review.
- Public RPC endpoints are rate-limited; use a dedicated provider for production.
- The earlier local-keypair helper `scripts/create-solana-fixed-supply-token.mjs` is optional and should only be used by developers who understand local key management. Never commit a keypair or expose secrets in frontend variables.

## Verification before marking complete

1. Deploy a test token on each test network using a throwaway wallet with test funds.
2. Verify Solana `mintAuthority` and `freezeAuthority` are null and raw supply equals 1,000,000,000 × 10^9.
3. Verify Robinhood testnet `totalSupply` equals 1,000,000,000 × 10^18 and confirm the contract has no mint function.
4. Verify explorer links, transaction status, wallet rejection, insufficient gas, and RPC failure handling.
5. Only mark on-chain fixed supply as complete after these checks pass.
